# Anten và Truyền sóng — IUH

Kho tài liệu học tập môn **Anten và Truyền sóng** tại IUH, được sắp xếp theo từng nhóm để dễ tra cứu, học tập và ôn thi.

## Nội dung repository

| Thư mục | Nội dung |
|---|---|
| `00_Chuong_trinh_mon_hoc/` | Đề cương / chương trình môn học |
| `01_Bai_giang/` | Bài giảng và tài liệu theo chương |
| `02_Giao_trinh/` | Giáo trình Anten và Truyền sóng, sách tham khảo chính |
| `03_Bai_tap/` | Bài tập và các dạng bài tập môn học |
| `04_On_tap/` | Tài liệu ôn tập, kiến thức và công thức tổng hợp |
| `05_Tai_lieu_tham_khao/` | Tài liệu tham khảo bổ sung |
| `06_PPT/` | Slide PowerPoint / tài liệu trình chiếu |
| `07_File_goc/` | Các file bài tập, đề thi và tài liệu gốc |
| `09_Tai_lieu_goc/` | File nén tài liệu gốc (`.rar`) |

Ngoài các thư mục trên, repository có tài liệu tổng hợp ở thư mục gốc như `Anten_va_Truyen_song_compressed.pdf`.

## Mục đích

- Tập trung tài liệu môn **Anten và Truyền sóng** vào một repository.

## Lưu ý bản quyền

Đây là repository phục vụ mục đích học tập. Một số tài liệu có thể thuộc bản quyền của giảng viên, tác giả, nhà xuất bản hoặc nền tảng cung cấp tài liệu. Vui lòng sử dụng phù hợp và tôn trọng quyền sở hữu trí tuệ.
